Privacy Policy

Last Updated: April 20, 2026

Aura Bot (the "Bot") is committed to protecting your privacy. This policy explains what data we collect and how we use it.

1. Data Collection

We collect minimal data required for functionality, including:

  • User IDs and Guild IDs for configuration and leveling systems.
  • Message content (only when processed by the AI system explicitly or for Moderation).
  • User avatars and usernames for display on the dashboard.

2. Data Usage

Data is used exclusively to provide bot features like auto-moderation, AI chat, and dashboard controls. We do not sell or share user data with third parties.

3. Data Deletion

Users can request data deletion by removing the bot from their server or contacting the developers. All guild-specific data is deleted when the bot leaves a guild.

4. Third-Party Services

We use Discord API for authentication and Google Gemini API for AI interactions.
