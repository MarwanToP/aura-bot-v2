## 2024-09-08 - Toggle Switch Accessibility
**Learning:** Custom toggle switches built with generic elements (like buttons with multiple nested divs and styling) in this app often lack crucial semantic accessibility attributes. Specifically, the `ToggleSwitch` component was missing a `role="switch"` and `aria-checked` state, making it opaque to screen readers despite having visual cues for its state. Additionally, `focus-visible` states weren't properly defined for keyboard navigation.
**Action:** When implementing or updating custom interactive components like toggle switches, always ensure they have explicit ARIA roles (e.g., `role="switch"`), dynamic ARIA states (`aria-checked={enabled}`), and clear keyboard focus indicators using Tailwind's `focus-visible` utilities.
