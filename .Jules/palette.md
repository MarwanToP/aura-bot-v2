## 2024-05-29 - Accessible Icon-Only Buttons in Glassmorphic UI
**Learning:** Interactive glassmorphic elements containing only icons must have explicit `aria-label` attributes for screen readers and `focus-visible` utility classes to ensure keyboard accessibility without breaking the visual aesthetic.
**Action:** Always add `aria-label` and `focus-visible` classes to icon-only `<button>` tags, ensuring keyboard navigation is clear.
