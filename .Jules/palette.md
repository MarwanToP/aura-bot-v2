## 2024-05-18 - Added Accessibility Attributes to Toggle Switches
**Learning:** Found an accessibility issue pattern specific to custom inline toggle buttons (`role="switch"`, `aria-checked`, and focus states missing). While a generic `ToggleSwitch` component existed, it lacked robust a11y properties, and inline versions in components like `ActiveAutomationWidget` missed them too.
**Action:** Always ensure custom switches implement `role="switch"`, an appropriate `aria-checked` state, semantic keyboard support with explicit focus indicators (e.g. `focus-visible`), and descriptive `aria-label`s when not wrapped with a semantic text label. Use standard Tailwind utility classes like `focus-visible:ring-offset-slate-900` instead of arbitrary hex colors to conform to the design system.
