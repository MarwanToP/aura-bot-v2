## 2026-11-05 - Toggle switch accessibility and keyboard navigation
**Learning:** Generic custom toggle switch components throughout the app lacked `role="switch"` and standard `aria-checked` attributes, making them difficult for screen reader users to understand. They were using `aria-pressed`, which is technically for toggle buttons, not switches. Furthermore, they were missing a `focus-ring` class which ties into our global CSS to provide `focus-visible` outlines for keyboard users.
**Action:** When auditing or implementing custom interactive controls, especially toggle switches, always use `role="switch"`, `aria-checked={value}`, ensure an `aria-label` is provided, and explicitly add keyboard focus styling (e.g., via the `focus-ring` class) to ensure proper screen reader and keyboard navigability.
