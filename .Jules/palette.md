## 2024-06-01 - Aura Dashboard Focus Ring Pattern
**Learning:** The application has a glassmorphic/dark theme UI with extensive interactive elements missing standard keyboard focus indicators (focus-visible). Applying consistent focus rings is necessary for a11y.
**Action:** Implement focus-visible rings using Tailwind classes (focus-visible:ring-2 focus-visible:ring-indigo-500 rounded outline-none) on icon-only buttons like header controls to improve keyboard navigation visibility.
