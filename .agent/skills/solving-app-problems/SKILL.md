# تشخيص وحل مشكلات التطبيقات (Advanced Problem Solving)

تهدف هذه المهارة إلى توفير إطار عمل منهجي لتشخيص الأخطاء وحلها بسرعة وفعالية، مع التركيز على بناء أنظمة مرنة (Resilient).

## قائمة التحقق للتشخيص (Diagnostic Checklist)

- [ ] **عزل المشكلة**: تحديد مكان الخطأ (Frontend, Backend, Database).
- [ ] **تحليل السجلات (Logs)**: فحص سجلات الخطأ للحصول على الـ Stack Trace والـ Error Code.
- [ ] **إعادة التكرار**: محاولة إعادة إنتاج الخطأ في بيئة التطوير.
- [ ] **التحقق من المدخلات**: التأكد من أن المشكلة ليست بسبب بيانات غير صالحة.
- [ ] **فحص الاتصالات**: التأكد من عمل الخدمات الخارجية (APIs, DB).

## أنماط الحلول (Implementation Patterns)

### 1. التعامل مع الاستثناءات (Exceptions)
استخدم `try-catch` بشكل منهجي مع تخصيص أنواع الأخطاء:
```javascript
try {
  await executeTask();
} catch (error) {
  if (error instanceof ValidationError) {
    handleValidation(error);
  } else {
    logToMonitoringSystem(error);
    showGracefulError(error);
  }
}
```

### 2. نمط Circuit Breaker
منع الفشل المتتالي عند تعطل خدمات خارجية:
- إذا فشلت الخدمة X مرات، توقف عن المحاولة لمدة Y ثانية.
- قدم "Fallback" (بيانات بديلة أو مؤقتة) للمستخدم.

### 3. التراجع التلقائي (Exponential Backoff)
عند فشل الطلبات الشبكية، أعد المحاولة بفواصل زمنية متزايدة (1s, 2s, 4s, ...).

## إرشادات الإصلاح
1. **أصلح السبب الجذري**: لا تكتفِ بإخفاء رسالة الخطأ.
2. **التثبيت (Stabilize)**: أضف اختبارات (Tests) تمنع تكرار هذا الخطأ مستقبلاً.
3. **التوثيق**: سجل المشكلة والحل في الـ Wiki الخاص بالمشروع.
